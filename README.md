\# 📰 NewsSense – News Sentiment Analyzer



NewsSense is a Python-based News Intelligence and Sentiment Analysis web application built with Streamlit.



It analyzes news articles and classifies their sentiment as \*\*Positive, Negative, or Neutral\*\*. The application also provides an interactive dashboard with statistics, charts, sentiment distribution, and company/news insights.



\---



\## 🚀 Features



\- 📰 News article analysis

\- 😊 Positive, Negative, and Neutral sentiment classification

\- 📊 Interactive sentiment dashboards

\- 📈 Visual charts and statistics

\- 🔎 News search and filtering

\- 🏢 Company/news intelligence

\- 💾 SQLite database integration

\- 🎨 Modern Streamlit dashboard

\- ⚡ Fast sentiment analysis

\- 📱 Responsive dashboard layout
